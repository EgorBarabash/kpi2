# ADR 0014: Тип помилки замість HTTP-кодів на діаграмах

**Статус:** Прийнято

**Контекст:** spec v1 (розділ 3) зіставляв BR з HTTP-кодами: BR-07 -> 403; BR-01, BR-02, BR-04, BR-06 -> 409; BR-03, BR-05 -> 422. AI-аналіз (`ai/answers/questions1.md`, Q2) показав, що в Gherkin і BR кодів немає, тож цю відповідність неможливо звірити зі сценаріями (критерій 7).

**Розглянуті варіанти:**
- *HTTP-коди 403/409/422 за групами BR.*
- *Один код 400 для всіх помилок.*
- *Лише тип помилки `ApplicationError(BR-xx)` з текстом із Gherkin.*

**Рішення:** На діаграмах return помилки - тип `ApplicationError(BR-xx)` з номером порушеного BR і текстом із Gherkin; HTTP-кодів немає. Помилка в S-06 - одна помилка BR-03 з двома частинами.

**Наслідки:**
- ApplicationController лише передає запит сервісу й повертає результат або помилку у WebUI.
- Кожен return помилки напряму звіряється з BR і текстом сценарію Gherkin.
