# ADR 0012: Порядок перевірок BR і зупинка на першому порушенні

**Статус:** Прийнято

**Контекст:** Під час подачі заявки (UC-04) ApplicationService перевіряє BR-01…BR-07. У лабі 2 порядок перевірок не зафіксовано. Від нього залежать усі помилкові діаграми: які виклики є на діаграмі до помилки і який текст отримує користувач, якщо порушено кілька BR одночасно.

**Розглянуті варіанти:**
- *Фіксований порядок BR-07 -> BR-04 -> BR-06 -> BR-01 -> BR-05 -> BR-03 -> BR-02 -> save, зупинка на першому порушенні.*
- *Перевірити всі BR і повернути список усіх порушень.*
- *Порядок як у переліку BR (BR-01 -> … -> BR-07).*

**Рішення:** Фіксований порядок BR-07 -> BR-04 -> BR-06 -> BR-01 -> BR-05 -> BR-03 -> BR-02 -> save; на першому порушенні сервіс повертає помилку, наступні перевірки й save не виконуються.

**Наслідки:**
- Розділ 4 spec і критерій 8 спираються на цей порядок; діаграми не можуть його змінювати.
- Перевірено: жоден сценарій S-01…S-12 не ламається - у кожному помилковому всі попередні BR проходять.
