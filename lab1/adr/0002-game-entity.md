# ADR 0002: Винесення гри в окрему сутність Game

**Статус:** Прийнято

**Контекст:** Назва гри потрібна в Tournament і в Game_Account. У моделі (коміт https://github.com/EgorBarabash/kpi2/commit/5c92f9ca8dda45422194c8146d05eb6e9029ceab) вона зберігалася рядком game_name в обох сутностях, тож «CS2» і «cs2» були б різними іграми. README вимагає турнірів «з різних ігор», а критерій 5 спершу не вимагав виносити довідкові значення — його посилено.

**Рішення:** Окрема сутність Game (id, name UK, logo_url); Tournament і Game_Account посилаються на неї через game_id (зв'язки 11 і 12 у spec).

**Розглянуті альтернативи:**
- *Рядок game_name у двох сутностях* — відхилено: назва дублюється, можливі різні написання (критерій 5).
- *Enum-тип з переліком ігор* — відхилено: кожна нова гра змінює розділ «Типи», до enum не додати logo_url.

**Наслідки:**
- Назва гри зберігається в одному місці й унікальна.
- До гри можна додавати власні атрибути без зміни інших сутностей.
- Для показу назви гри в турнірі потрібен зв'язок із Game.
