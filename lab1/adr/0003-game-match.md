# ADR 0003: Id матчу з гри в атрибуті Match.match_game_id

**Статус:** Прийнято

**Контекст:** Матч на платформі відбувається в грі, але без посилання на матч у грі неможливо перевірити результат чи підтягнути статистику гравців. Формати ідентифікаторів матчів різняться між іграми.

**Рішення:** Атрибут match_game_id (string) у сутності Match.

**Розглянуті альтернативи:**
- *Не зберігати id, вносити результати вручну* — відхилено: результати й статистику неможливо перевірити.
- *Окрема сутність для матчу з гри (1:1 з Match)* — відхилено: зв'язок один до одного без власних атрибутів, сутність надлишкова.

**Наслідки:**
- Матч можна знайти в грі; string підходить для будь-якого формату id.
- Унікальність match_game_id не позначена на діаграмі: гра визначається ланцюжком Match → Encounter → Tournament → Game, а game_id у Match дублював би ці дані (критерій 5).
