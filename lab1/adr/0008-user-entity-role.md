# ADR-0008: Роль користувача на платформі

**Статус:** Прийнято

**Контекст:** UC-16 «Додати гру» виконує Адміністратор платформи, але в ERD User не має ознаки, що відрізняє адміністратора від звичайного користувача.

**Рішення:** додати до User атрибут role (user, admin).

**Розглянуті альтернативи:**
- Нова сутність User_Role (довідник ролей) - відхилено: для двох ролей створювати окрему сутність не раціонально.
- Атрибут is_admin (boolean) - відхилено: критерій 7 не допускає типу boolean.

**Наслідки:** перевірка «ігри додає лише адміністратор» спирається на User.role.
