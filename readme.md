Домен

Платформа для проведення аматорських турнірів з різних ігор.
Користувачі створюють команди й подають заявки на турніри, організатори формують турнірну сітку
із зустрічей (BO1/BO3/BO5), а платформа зберігає результати матчів і статистику гравців.
Один гравець може бути одночасно в кількох командах і грати в різні ігри.
